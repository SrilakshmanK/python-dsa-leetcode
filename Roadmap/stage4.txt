Stage 4 — Strings
🎯 Objective

Master string manipulation techniques, understand common string patterns, and solve interview-style string problems efficiently.

Outcome:
After completing this stage, you should confidently solve most Easy and Medium string problems and recognize common string manipulation patterns.

📖 Why Strings Exist

A string is simply an array of characters.

However, interview questions involving strings often focus on:

Character manipulation
Pattern matching
Frequency counting
Parsing
Validation

Many advanced algorithms later (Trie, KMP, Rabin-Karp) are built upon these fundamentals.

⏱️ Complexity

Operation	Complexity

❌ Common Mistakes
Forgetting strings are immutable in Python.
Off-by-one errors.
Incorrect slicing.
Confusing characters with words.
Ignoring uppercase/lowercase.
Forgetting whitespace handling.
Building strings inefficiently inside loops.
🎯 Interview Tips

When you see a string problem, ask:

Do I need to reverse?
Is it a palindrome?
Am I comparing characters?
Can slicing help?
Should I use built-in methods?
Is this actually a HashMap problem disguised as a String problem?
