📘 Stage 1 — Foundation Programs
🎯 Objective

Build a strong understanding of the core programming concepts that every developer must master before solving logical problems or learning advanced topics.

Outcome:
After completing this stage, you should be comfortable writing simple programs, understanding how code executes, and using the fundamental building blocks of any programming language.

Why This Stage Exists

Programming is more than memorizing syntax.

Before learning problem-solving, you must understand how a program is built, how data flows through it, how functions work, and how Object-Oriented Programming organizes code.

These concepts remain the same whether you use Python, Java, C++, JavaScript, or C#.

Completion Criteria

Move to Stage 2 only if you can:

✅ Write programs using variables, loops, and conditions confidently.

✅ Create and call functions without help.

✅ Explain the difference between local and global variables.

✅ Work comfortably with strings and collections.

✅ Understand how objects and classes interact.

✅ Explain the four pillars of OOP in your own words.

✅ Read a simple program and predict its output before running it.
