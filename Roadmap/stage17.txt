📖 Why Dynamic Programming Exists

Imagine calculating:

fib(5)

The recursion tree looks like this:

                fib(5)
               /      \
          fib(4)      fib(3)
          /    \      /    \
      fib(3) fib(2) fib(2) fib(1)
      /   \      \
 fib(2) fib(1) fib(1)

Notice something?

You calculate:

fib(3)

multiple times.

You calculate:

fib(2)

multiple times.

You're doing the same work again and again.

Dynamic Programming says:

"If I've already solved it once, why solve it again?"

Instead...

Store the answer.

Reuse it.

That's Dynamic Programming.
